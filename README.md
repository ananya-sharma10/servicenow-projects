# ServiceNow Projects

A collection of ServiceNow workflow automation and ITSM projects built to demonstrate practical experience with ServiceNow platform capabilities.

These projects focus on workflow automation, Service Catalog, Flow Designer, Incident Management, and service operations.

---

## Projects

### 1. Integrated Employee Onboarding System

A ServiceNow workflow automation project designed to streamline employee onboarding across HR, IT, and Facilities teams.

The system uses a centralized onboarding request to coordinate approvals and automatically generate tasks required before a new employee joins the organization.

**Key concepts demonstrated:**
- Service Catalog
- Catalog Items
- Flow Designer
- Automated task generation
- Approvals
- Notifications
- Service Portal
- Cross-team workflow automation

[View Project →](integrated-employee-onboarding/)

### 2. Advanced ITSM & Incident Management

A ServiceNow ITSM project focused on incident management, workflow automation, incident analysis, and service operations.

The project demonstrates how incidents can be created, categorized, prioritized, assigned, analyzed, and processed through automated workflows.

**Key concepts demonstrated:**
- Incident Management
- Flow Designer
- Incident workflows
- Assignment Groups
- Incident prioritization
- ITSM dashboards
- Incident analysis
- Resolution tracking
- ServiceNow reporting
